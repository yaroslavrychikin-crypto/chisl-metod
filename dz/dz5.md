# Задача: сумма по строкам и максимумы — цикл vs NumPy

## Условие

Дан массив `m` формы `(200 000, 5)` — 200 000 строк по 5 чисел. Нужно посчитать **две вещи**:

1. Сумму каждой строки (результат — массив из 200 000 чисел).
2. Максимум каждого столбца и его индекс (результат — 5 чисел и 5 индексов).

Никаких NaN, никаких нормировок. Только циклы против NumPy.

---

import time
import numpy as np

    col_max = [0.0] * k
    col_arg = [0] * k

    return row_sums, col_max, col_arg


# ── Способ 2: NumPy ────────────────────────────────────────
def numpy_version(mat):
    # TODO
    return row_sums, col_max, col_arg


# ── Замер: 3 раза, берём лучший ────────────────────────────
def measure(fn, x, repeat=3):
    best = float("inf")
    result = None
    for _ in range(repeat):
        t0 = time.perf_counter()

        t1 = time.perf_counter()

## На что обратить внимание при запуске

- **Суммы строк** в цикле и в NumPy могут отличаться в последних знаках (разный порядок суммирования), поэтому проверка — `np.allclose`, а не `==`.
- **Максимумы и индексы** должны совпадать **точно** (`np.array_equal`): здесь нет накопления ошибки, только сравнения.
- Цикл медленнее примерно в **30 раз** — это нормально: 200 000 × 5 = 1 000 000 итераций на сумму плюс 1 000 000 на поиск максимумов, всё в Python.
